# GRAMMER Offroad Intelligence Hub - V16.5 Content Pack V1

## Purpose
This package populates the customer and competitor profile pages with the rich Level 1 / Level 2 / Level 3 structure already supported by the portal.

## Files
Replace in `offroad-intelligence/data/`:

- `customer_profiles.json` with `customer_profiles_v16_5_content.json`
- `competitor_profiles.json` with `competitor_profiles_v16_5_content.json`

## What it adds

### Customer profiles
- Level 1 Permanent Facts
- Level 2 Quarterly Facts
- Level 3 Dynamic Intelligence
- Account Opportunity object

### Competitor profiles
- Permanent facts
- Quarterly facts
- Strengths / weaknesses
- Questions to ask
- GRAMMER counter-message
- Competitor momentum placeholder

## Important
Several value, probability and timing fields are intentionally marked as TBD / To validate because account-level validation is needed.
